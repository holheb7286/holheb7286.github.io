# Holly's Portfolio

This portfolio website showcases projects, skills, and interactive JavaScript functionality developed throughout coursework and independent practice.

## Features

- Dynamic project rendering with JavaScript objects
- Session storage and local storage
- Dark mode toggle
- Interactive modal window
- Dynamic DOM manipulation
- Form interaction with delayed confirmation messages

## Languages Used

- HTML5
- CSS3
- JavaScript

## Libraries / APIs

- Browser Local Storage API
- Browser Session Storage API

## Dependencies

No external installation is required.  
Open the HTML file in a browser or deploy using GitHub Pages.
